# Lab head

The lab head keeps the list of parameters each person may test.

## Parameter authorizations

- Adds, changes and removes the parameters each person is authorized to test. Nobody else changes them; every internal user reads them.
- Removing an authorization keeps the person's existing assignments and bookings, but they are no longer assigned, claim or are booked for that parameter.
