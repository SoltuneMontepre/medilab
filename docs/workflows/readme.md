# Workflows

Step-by-step procedures for recurring tasks.

- [Creating an issue](creating-issue.md): turn a documented feature into a GitHub feature issue and assign it
- [Resolving an issue](resolving-issue.md): implement the lowest open issue, check it in the browser and open its pull request
- [Creating a pull request](creating-pr.md): open a pull request, wait for the pipelines and fix what SonarQube reports
