# Workflows

Step-by-step procedures for recurring tasks.

- [Creating an issue](creating-issue.md): turn a documented feature into a GitHub feature issue and assign it
- [Resolving an issue](resolving-issue.md): implement the lowest open issue, check it in the browser and open its pull request
- [Reporting a bug](reporting-bug.md): turn a defect into a GitHub bug issue linked to the rule it breaks
- [Fixing a bug](fixing-bug.md): reproduce the lowest open bug, prove it with a failing test, fix it and open its pull request
- [Creating a pull request](creating-pr.md): open a pull request, wait for the pipelines and fix what SonarQube reports
- [Syncing the database diagram](syncing-database-diagram.md): bring a module's Prisma diagram in line with the tables Odoo creates
- [Reviewing a pull request](reviewing-pr.md): check a pull request against the conventions, business rules and database, and post the review
- [Setting up](setting-up.md): install the modules and configure the company, languages, settings and code formats
