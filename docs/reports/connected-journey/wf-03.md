## Connection findings

1. **A person notified by e-mail sees no notice in the browser.** The demo people are notified By Emails. The assignment and approval notices are then e-mailed and no screen of the back office lists them. The tester has no New on Jobs → Notification preferences, so she cannot choose the application for one event; the journey has her choose **In Odoo** in My Preferences, which moves all her notices to the messaging menu.
2. **A notice does not reach a browser that is open.** The messaging menu reads the notices once. The approval notice, sent while the tester's page was open, is absent from the menu and from its counter until the page loads again: the server announces it on the channel `mail.message/inbox`, which the web client of Odoo 20 does not listen to. The spec reports this check as failed, then loads the page again.
3. **Assign Sample assigns every task of the sample.** The row button Assign Sample would give the tester the Lead task too. One task is assigned by ticking its row and pressing Actions → Assign; the task's own form cannot be reached from a task list, whose rows open the sample test.
4. **Bookings name a machine without its code.** The sample test, the booking and the Machine Schedule show `UV-Vis spectrophotometer 1`; the code `UVVIS-01` shows only on the machine's form, reached by the booking's link. The Machine Schedule's first search suggestion is Machine, so a parameter name is searched under Sample Test.
5. **The test stays Assigned after the approval.** It turns Testing when its booking starts, which is WF-04's first click.
6. **Start is offered on a booking that starts in the future.** The tester's booking form and the Bookings row of the sample test show Start as soon as the booking is Scheduled, hours before its slot; the code refuses a start only for a booking that is not Scheduled or belongs to someone else. The journey does not press it. The sample test also offers the tester Enter Result before the booking starts.
7. **The approval notice writes the start with seconds and without a time zone,** `11/27/2026 10:00:00 AM`, in the company's time.
8. **The notice of an assignment says "1 tasks go to".**
9. **The reminder before the start is not walked.** It is sent by a scheduled job 15 minutes before the booking, which no business screen runs.

Read in the code, not walked: a requested date too close leaves no slot before the due date, the test is flagged for outsourcing and Approve Booking never shows; without the department's scan no booking is proposed; a proposal that became stale is recalculated at approval, which is why the spec reads the slot after it.
