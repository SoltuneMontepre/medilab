# Frontend conventions

Code rules for the web client: views, templates, styles and scripts.

## Icons

- **Odoo icon names.** A button's `icon` and an `<i class="oi" data-icon="…">` take a Material Symbols name of Odoo's icon font, such as `history` or `lock_open`. A Font Awesome name such as `fa-history` is not in that font and shows as stray characters beside the icon.
