Medilab - Laboratory

The core of the MediLab laboratory information management system. Manage what your laboratory tests, how it tests it, and every sample from reception to result.

Test catalog

Test parameters with unique codes, grouped and filtered by sample type.

Samples and requests

Receive samples, record test requests and follow each one through the laboratory.

Results and machines

Enter and review results, and keep track of the machines used for testing.

Works with the other MediLab apps

Install Medilab - E-commerce for the customer portal, quotations and invoices, and Medilab - Inventory for chemical stock and suppliers. Both build on this module, which also provides the MediLab theme and English and Vietnamese translations.
